# QuickTask - Kazi Task Tracker

QuickTask is a Python command-line application that helps students manage their tasks by creating, deleting, completing, and viewing pending tasks.

## Features
- Add tasks with unique IDs
- Delete tasks by ID
- Mark tasks as completed
- View pending tasks
- Handle invalid inputs with appropriate error messages
- Automated testing with pytest
- Continuous Integration (CI) using GitHub Actions

## Getting Started

**Requirements:** Python and Poetry.

Clone the repository and install dependencies:

```bash
git clone https://github.com/erickkanja-code/kazi-task-tracker.git
cd kazi-task-tracker
poetry install --with dev
```

Run the application:

```bash
poetry run python quicktask.py
```

Run the tests:

```bash
poetry run pytest
```
